# 連立方程式 練習ドリル

iPad で動く、連立方程式と「比の変換」の自動生成ドリル。
手書き計算メモ（Apple Pencil / 指）を同じ画面に備え、直近10問の正答率でレベルが自動調整されます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 本体（外部通信ゼロ・1ファイル完結） |
| `sw.js` | Service Worker。オフライン起動用 |
| `manifest.webmanifest` | ホーム画面追加時の設定（全画面表示） |
| `icon-180.png` / `icon-512.png` | アプリアイコン |

---

## 1. GitHub Pages に公開する手順

1. GitHub にログインし、**New repository** を作成
   - Repository name: `renritsu-drill`（任意）
   - **Public** を選択（無料プランでは Pages は Public のみ）
   - 「Add a README file」は**チェックしない**
2. 作成後の画面で **uploading an existing file** をクリック
3. このフォルダ内の **5ファイルすべて**（`index.html` / `sw.js` / `manifest.webmanifest` / `icon-180.png` / `icon-512.png`）をドラッグ＆ドロップ → **Commit changes**
4. リポジトリの **Settings** → 左メニュー **Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** → **Save**
5. 1〜2分待つと Pages の画面に URL が表示されます
   `https://<ユーザー名>.github.io/renritsu-drill/`

## 2. iPad でアプリとして使えるようにする

1. iPad の **Safari** で上記 URL を開く
2. 画面下部（または右上）の **共有ボタン**（□に↑）をタップ
3. **「ホーム画面に追加」** をタップ → 追加
4. 以後、**ホーム画面のアイコンから全画面で起動**します
   - Safari のアドレスバー・タブバーが消え、手書きメモ欄が縦に広く使えます
   - 一度起動しておけば、**オフラインでも動きます**

> 初回だけネット接続が必要です（Service Worker がファイルを保存するため）。

## 3. 内容を更新したいとき

1. GitHub 上でファイルを差し替える（`index.html` をアップロードし直す）
2. **`sw.js` の `var CACHE = 'renritsu-drill-v1';` の版番号を上げる**
   （例: `renritsu-drill-v2`）
   ※ これをやらないと iPad に古い版が残り続けることがあります
3. iPad でアプリを起動すると、次回起動時までに自動で新しい版に入れ替わります

## アプリの仕様

### 出題レベル（直近10問のスライディングウィンドウで自動調整）

| Level | 内容 |
|---|---|
| 1 基礎 | 係数がそろっていて、足すか引くだけで消える加減法 |
| 2 標準 | 何倍かして係数をそろえる加減法（負の係数を含む） |
| 3 弱点特訓 | かっこ外し（`−( )` を高頻度で出題）＋ `ax = by → x : y` の比の変換 |
| 4 実戦 | 分数（分母をはらう）・小数（10倍する）・複雑な移項 |

- **昇格**: 直近10問で **9問以上正解**
- **維持**: 6〜8問正解
- **降格**: 5問以下正解（Level 1 では降格なし）
- レベルが変わったタイミングでウィンドウはリセットされます（連続昇格・連続降格の暴発防止）

### 出題ロジックの保証

解（x, y）を先に整数で決めてから係数を逆算し、生成後に必ず検証しています。

- **判別式 `a1*b2 − a2*b1 ≠ 0`**（解が無数／不能になる問題を排除）
- 2式が同一でないこと
- 解が実際に両方の式を満たすこと
- 定数項が大きくなりすぎないこと

> 44,000問を自動生成して検証済み（不良 0 件）。

### 採点と解説

- 誤答時は**途中式つきの解説を自動で展開**します
- 比の問題は**最も簡単な整数の比のみ正解**。約分し忘れは「△」として指摘します
- 比の解説には「係数がそのまま並ぶのではなく**入れかわる**」という注意書きと、代入による確かめを必ず表示します

### 手書きメモ

- Pointer Events による Apple Pencil / 指の両対応
- ペン使用中は指の入力を無視（手のひら誤爆の防止）
- Retina 解像度対応。画面回転・リサイズでも**描いた内容は消えません**

### その他

- 「比だけ特訓」ボタンで、比の変換だけを連続練習できます（この間はレベル判定に影響しません）
- 進捗（レベル・直近成績）は iPad 内に保存されます。「進捗をリセット」で初期化できます
- 画面最上部の赤帯は自己診断用です。JavaScript のエラーが起きた場合のみ表示されます
